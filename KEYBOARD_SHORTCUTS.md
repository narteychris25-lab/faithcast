# Keyboard shortcuts

## Live presentation

These work in the Live view, and anywhere in the app while the output is open (except while typing in a text field). They also work when the output window has focus. You can change them in **Settings → Keyboard**.

| Action | Keys |
|---|---|
| Next slide | → · Space · ↓ · Page Down |
| Previous slide | ← · ↑ · Page Up |
| First slide of item | Home |
| Last slide of item | End |
| Next service item | ⇧→ · N |
| Previous service item | ⇧← · P |
| Black screen (toggle) | B · . |
| Clear text, keep background (toggle) | C |
| Show church logo (toggle) | L |
| Pause / resume media | K |
| Exit presentation | Esc |
| Global search | ⌘K · ⌘F |

Most presentation remotes send Page Up/Page Down or arrow keys, so they work without any setup.

## App

## Bible page

| Action | Keys |
|---|---|
| Switch to the 1st … 9th Bible version (in the order of the version buttons) | ⌥1 … ⌥9 |

## Service planner (with the service list focused)

| Action | Keys |
|---|---|
| Select previous / next item | ↑ / ↓ |
| Move item up / down | ⌥↑ / ⌥↓ |
| Duplicate item | ⌘D |
| Delete item | ⌫ |
| Edit item | Return |

## Slide editor

| Action | Keys |
|---|---|
| Nudge element | Arrow keys (⇧ = 10 px) |
| Undo / redo | ⌘Z / ⇧⌘Z |
| Duplicate / delete element | ⌘D / ⌫ |
| Deselect | Esc |
| Keep aspect ratio while resizing | Hold ⇧ on a corner handle |
| Snap rotation to 15° | Hold ⇧ while rotating |
| Disable alignment snapping | Hold ⌥ while dragging |

## Scripture box (Bible page, planner, Bible items)

| Action | Keys |
|---|---|
| Accept the suggested book and move to Chapter | Space · a chapter number · : · Tab · → · Return |
| Chapter → Verse box | : · Space · Tab |
| Go back to the previous box | ⌫ in an empty box |
| Choose another suggested book | ↑ / ↓ |
| Remove the suggestion, keep what you typed | ⌫ |
| Close the suggestion list | Esc |
| Open / add the reference | Return (in any box) |

Example: typing `joh3:16-18` fills Book **John**, Chapter **3**, Verse **16-18**.

## Search palette

↑ / ↓ to choose, Return to open, **⌘Return** to present a song or Bible passage immediately.
